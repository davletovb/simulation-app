**Release limits:** The first case specifies *delivery-paid tranche milestones*, not arbitrary new audit-dependent trust-fund/escrow triggers. A promise or ratification does **not** release money; payment is authorized only when already funded work is actually delivered. Reallocation keeps the same scope's partial carry and refuses reducing below pending protected units. No recurring maintenance fee outside its explicit funded service units, no debt or automatic refill. Future extensions must be versioned and should not smuggle in policy effects absent from the authored case.

**Custody boundary into P4:** The present P1 wire checkpoint stores `WorldSnapshot` but not the entire additional P3 `Campaign` state (meeting, command IDs, privately retained effort, audited evidence, historical due shadow scopes, ballots and belief updates). P4 must version that private reducer envelope, persist and replay the full state with pack SHA and cursor binding, and ensure that public HTTP projections never serialize `WorldSnapshot` or `ReducerReceipt` truth. ## PR #10 review corrections (2026-10-30)

- **Source-to-credit accounting:** each commitment binds an originating scope and has its own credited-unit counter. Each service receipt is allocated once in deadline/immutable-ID order. Later funding proposals preserve precisely the undelivered protected units; older unassociated scopes cannot honor new promises.
- **Admission:** a deadline before activation+lag has zero eligible periods and is rejected. Reused meeting IDs fail before a meeting slot is consumed; proposal caps still require a new version. The independent scripted actor uses a feasible typed counteroffer when every initial menu entry exceeds the remaining budget.
- **Sensitivity:** ratification uses the reducer's own verdict; aggregate and group comparisons share the same admitted-pair source. Q6 ties and pending responses are recorded explicitly; derived queued-response settlement is shown separately and never treated as gameplay Q6 support.
- **Authored Q2 repair narrative:** the cap=8 overlay remains pinned as P2 content but cannot bind before repairs activate in Q3; it is reported as inert, not as a tested consequential shock.
- **Audit threshold distinction:** P0-03 deliberately uses inclusive `missed >= 200` but strict `overreport > 200`; exact 20% missed work is severe while exact 20% over-report is moderate. The existing case-contract semantics were **not** silently rewritten; exact boundary tests now pin this asymmetry. Changing it requires a versioned case contract.

These changes do not imply P4 durable custody or an empirical sensitivity guarantee.
